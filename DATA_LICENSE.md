# Data-use note

The artifact's original code is released under the MIT license in `LICENSE`.
The LNCS class and bibliography style retain the notices in their source files.

Source data are included for research reproducibility. Bitcoin release details
and source links appear in `data/readme_top_mill_addresses.md`; the Ethereum
projection metadata records its Beacon API source and derivation. The published
ten published validator inputs retain their original bytes and have a pinned upstream
revision in `review/data/motepalli2025/README.md`.

This artifact does not grant rights beyond those of the upstream data providers.
Consult their terms before redistributing source data. The supplied records and
withdrawal-address groups do not establish real-world controller identities.
