Decentralization Certificate Calculator

Explore intervals for decentralization metrics when holdings are missing or their controllers are uncertain. Default dataset: Bitcoin top-10k balance records, 2025-09-23.

Input

Upload format

Accepted: JSON, CSV, TSV, or plain text (one value per line). All values are interpreted as positive numeric balances; address labels are ignored.

JSON, flat array:

[248597.58, 140574.83, 140398.42, ...]

JSON, object (either shares_descending or shares is accepted; sorting is done internally):

{
  "shares_descending": [248597.58, 140574.83, ...]
}

CSV / TSV / TXT: one balance per line. If a line has multiple comma/tab/space-separated tokens, the last numeric token is used. Headers are accepted (skipped automatically). Examples:

balance
248597.58
140574.83
140398.42
address,balance_btc
34xp...,248597.58
bc1q...,140574.83

Normalization: the uploaded vector is sorted descending and normalized by its own sum, so it is treated as the complete distribution of observed labels by default. Labels need not have different controllers. To analyze a capped observation, set omitted mass TN; the visible balances are then scaled to sum to 1 − TN. Clear the field to restore the dataset denominator.

Size limits: practical limit is ~5–10 M entries. The calculator runs entirely in your browser; nothing is uploaded to any server.

Attribution budgets

Both budgets limit the fraction of resource moved. Merge combines whole holdings: in each group, the largest holding stays and all others move to it. Shift also permits moving part of a holding and creating additional controllers.

Reference paper: How informative are distribution-based decentralization metrics? Certificates under capping and attribution uncertainty (FC27 version). This page implements the capping and composition results, with Merge defined by moved mass. All calculations run locally in your browser; nothing is uploaded.

Status badges: exact = recovered from the observation; interval = sharp identified-set endpoints; conservative = valid but possibly loose bound; descriptive = an observed-label summary, without a claim about controllers. “Not computed” means this calculator does not implement a bound for that metric and model.
